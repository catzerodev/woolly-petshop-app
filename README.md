# 🐾 Woolly PetShop

Woolly PetShop is a modern ecommerce web application focused on premium pet products and services.  
The project was developed with a clean iOS-inspired design system, responsive UI, dynamic product search, shopping cart functionality, and an admin dashboard connected to Supabase.
woolly-petshop.netlify.app

---

# ✨ Features

## 🛍 Ecommerce Experience

- Product catalog
- Dynamic search bar with live filtering
- Shopping cart system
- Add / remove products
- Toast notifications
- Responsive design
- Premium UI/UX inspired by Apple/iOS aesthetics

---

## 🔎 Smart Search

The application includes a live search system that:

- Filters products instantly
- Displays animated dropdown suggestions
- Works on Home and Shop pages
- Improves user navigation and product discovery

---

## 🧺 Shopping Cart

Implemented using Zustand for global state management.

Features include:

- Add products to cart
- Persistent cart state during session
- Dynamic cart updates
- Purchase confirmation UX

---

## 🔐 Admin Dashboard

The application includes an admin dashboard for product management.

### CRUD Operations

- Create products
- Read products
- Update products
- Delete products

The dashboard is connected to Supabase as backend service.

---

# ☁️ Supabase Integration

Supabase is used as Backend-as-a-Service (BaaS).

The project consumes Supabase REST API for:

- Database operations
- Product persistence
- CRUD functionality

### Database Table

Products table includes:

- id
- name
- price
- image
- stock
- category
